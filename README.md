# Portfolio

Portfolio d'Emmanuel Mbroumsadja, développeur full-stack à Garoua.

Page statique en HTML, CSS et JavaScript, sans étape de build. Ouvrir `index.html` dans un navigateur pour la voir.

Pour renseigner un e-mail ou un numéro WhatsApp dans la section Contact, modifier l'objet `CONTACT` en bas de `index.html`.
